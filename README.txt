# Marketing Performance Optimization Analysis
Marketing Performance Optimization for a Growing E-Commerce Company.
The company runs monthly marketing campaigns using:
● Facebook Ads
● Google Ads
● Influencer promotions
● Seasonal discount campaigns

## Project Overview
Analyzes marketing spend and customer acquisition data (Jan–Oct 2024)
to calculate monthly CAC, detect anomalies, and generate insights.

## Files
- `Marketing_Data_Analysis.py` – Main analysis script
- `Executive_Summary – Business report
- `marketing_data.csv` – Input data (columns: date, marketing_spend, new_customers)
- `CAC_Trend.png` – CAC trend chart
- `marketing_report.xlsx` – Monthly summary (Excel)
- `marketing_report_clean.csv` – Cleaned data (CSV) 
- 'marketing_data.csv' - raw data (CSV)

## How to Run
1. Install dependencies: `pip install -r requirements.txt`
2. Place `marketing_data.csv` in the same folder
3. Run: `python Marketing_Data_Analysis.py`

## Outputs
- `CAC_Trend.png` – CAC trend chart
- `marketing_report_22304071.xlsx` – Monthly summary (Excel)
- `marketing_report_clean_22304071.csv` – Cleaned data (CSV)
